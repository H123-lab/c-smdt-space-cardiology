================================================================================
C-SMDT Third-Party Open Data Licenses Registry
================================================================================

This project integrates open-access data structural layouts from several upstream 
scientific initiatives. This file explicitly documents the usage terms and 
licensing boundaries required by their respective open-access agreements:

1. NASA Open Science Data Repository (OSDR)
   - Status: Public Domain Data.
   - Redistributed Content: Anonymized structural coordinate sets.
   - Terms: Attribute NASA OSDR spaceflight control cohorts natively in 
     manuscript methods. (COMPLIANT).

2. OpenNeuro Database
   - License type: Creative Commons CC0 1.0 Universal Public Domain Dedication.
   - Content: Anonymized DT-MRI tracking tensor voxel sets.
   - Terms: Open access redistribution permitted with zero copyright constraints. 
     (COMPLIANT).

3. Living Heart Project Reference Framework
   - License type: Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0).
   - Content: Hyperelastic myocardium performance benchmarks.
   - Terms: Permitted to adapt and share under matching attribution layers. 
     (COMPLIANT).

4. SimVascular Boundary Circuit Parameter Registry
   - License type: SimVascular Open Source Software License (BSD 3-Clause variant).
   - Content: Lumped-parameter afterload validation equations.
   - Terms: Redistribution permitted provided original copyright definitions 
     remain intact. (COMPLIANT).
