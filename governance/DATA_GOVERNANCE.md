# Data Governance Framework

This document outlines the administrative rules, stewardship responsibilities, and management frameworks governing the simulation logs and parameters arrays generated by the Cardio-Spatial Multi-Domain Digital Twin (C-SMDT) framework.

## 1. Data Classification
All data files generated or stored within this repository are classified as **Public Open-Access Data**. None of the code paths or simulation outputs contain operational security metrics, confidential space program data, or proprietary corporate information.

## 2. Retention and Maintenance
* **Data Lifecycle**: The processed CSV outputs and parameters trees contained in this repository are permanently version-controlled and matching the release DOI version of the published manuscript.
* **Long-Term Storage**: Long-term binary storage targets ($>100\text{ GB}$ containing raw volumetric time-resolved uncompressed transient field results) are archived externally via Zenodo using metadata tags indexed to this master repository branch.
