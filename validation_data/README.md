# Validation Data Registry

This directory contains the numerical baseline metrics and raw logging data arrays used to benchmark and validate the C-SMDT simulation pipeline accuracy loops.

* **`raw_simulation_outputs.csv`**: Contains the aggregated multi-physics engine readouts (LVM, EF, SV, GLS, wall thicknesses) stepped along the 12-month spaceflight exposure timeline.
* **`dynamic_benchmarks.json`**: Standardizes the physiological acceptance envelopes compiled from -6° HDT clinical ground studies and active ISS flight datasets.
